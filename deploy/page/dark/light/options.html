Google Chrome hides extensions by default but you can use the extensions menu in the upper right of Chrome to enable the pin option for Script Control.

The above procedure will allow the Script Control status icon to be visible and enable one-click access.

Microsoft Edge hides extensions by default but you can use the extensions menu in the upper right of Edge to enable the eye option for Script Control.

The above procedure will allow the Script Control status icon to be visible and enable one-click access.

Mozilla Firefox hides extensions by default but you can use the extensions menu in the upper right of Firefox to click on the gear for Script Control which will then reveal a "Pin to Toolbar" option.

The above procedure will allow the Script Control status icon to be visible and enable one-click access.
